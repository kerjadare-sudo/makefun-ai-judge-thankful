## What it does

`main.py` (Python 3.13, no dependencies, no network) writes one short
thank-you text to `/output/entry.txt`.

The text is 1–1,000 characters, plain UTF-8, and is written by the
program itself — it is not pasted in by hand at submit time.

## Run

```sh
python3 main.py
```

Then read `/output/entry.txt`.
